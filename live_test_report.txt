# סיכום לימוד JavaScript - חלק א׳: יסודות השפה

## מה זה JavaScript
- **הסבר פשוט**: שפת תכנות המאפשרת לבצע פעולות בדפדפן (כגון Chrome, Firefox) ובשרת (Node.js).
- **למה צריך את זה?**: 
  - לבדוק קלט בטופס.
  - לפתוח תפריט בלחיצה.
  - לעדכן נתונים בלי לרענן את הדף.

## דרכים להריץ קוד
1. **Console**: F12 בתוך הדפדפן.
2. **תגית script**: קוד בתוך תגית `<script>`.
3. **קובץ נפרד**: קובץ בשם `script.js`, מקושר מהתגית `<script src="script.js"></script>`.

### דוגמה
```javascript
console.log(5 + 3);
```
- **פלט**: 8

### מה חשוב לזכור
- `console.log()` היא הפקודה הבסיסית להצגת פלט ולבדיקת קוד.

### טעויות נפוצות
- לשכוח לסגור סוגריים או מרכאות.
- לבלבל בין `console.log` ל`Console.log`.
- לשכוח נקודה-פסיק בסוף שורה (לא חובה, אך מומלץ).

## משתנים
- **הסבר פשוט**: משתנה הוא "קופסה עם שם" ששומרים בתוכה ערך.
- **למה צריך את זה?**: 
  - מאפשרים לתת שם ברור לערך.
  - לשנות ערך במקום אחד והשפעה בכל מקום שמשתמשים בו.

### דרכים להגדיר משתנה
1. **let**: כשערך עשוי להשתנות.
2. **const**: כשערך לא אמור להשתנות.
3. **var**: ישן, כמעט ולא בשימוש היום.

### כללי שם למשתנה
- חייב להתחיל באות, `_` או `$` (לא במספר).
- אין רווחים (כגון `firstName`).
- רגיש לאותיות גדולות/קטנות.
- אסור להשתמש במילים שמורות (כגון `let`, `if`).

### דוגמה
```javascript
let name = "דניאל";
let age = 25;
console.log(name); // דניאל
console.log(age); // 25
```
- **שגיאה**: `const age = 25; age = 30;` → TypeError: Assignment to constant variable.

### מה חשוב לזכור
- משתנה = קופסה עם שם ששומרת ערך.
- `let` - ערך שיכול להשתנות.
- `const` - ערך קבוע.
- `var` - ישן, כמעט ולא בשימוש.

### טעויות נפוצות
- לנסות לשנות משתנה `const`.
- לבלבל בין `=` (השמה) ל-`==/===` (השוואה).
- להשתמש באותו שם משתנה פעמיים עם `let` באותו תחום.

## טיפוסי נתונים
- **הסבר פשוט**: כל ערך ב-JavaScript יש לו טיפוס נתון.
- **למה צריך את זה?**: כל פעולה בקוד תלויה בסוג הנתון.

### הטיפוסים הבסיסיים
1. **Number**: 25, 3.14, -10 (כל מספר — שלם או עשרוני).
2. **String**: "שלום", 'Hello' (טקסט, במרכאות).
3. **Boolean**: true, false (ערך אמת/שקר).
4. **Undefined**: משתנה שהוגדר אך לא קיבל ערך.
5. **Null**: ערך ריק במכוון.

### בדיקת טיפוס
- ניתן לבדוק טיפוס עם `typeof`:
```javascript
let age = 25;
let name = "נועה";
let isStudent = true;
console.log(typeof age); // number
console.log(typeof name); // string
console.log(typeof isStudent); // boolean
```

### מה חשוב לזכור
- טיפוסים בסיסיים.
- `typeof` בודק את הטיפוס של ערך.
- `undefined` = משתנה שלא קיבל ערך כלל.
- `null` = ערך ריק שנקבע בכוונה.

### טעויות נפוצות
- לבלבל בין `null` ל`undefined`.
- לחשוב ש`5 + "3"` יהיה 8 — בפועל זה `53`.
- לשכוח מרכאות סביב טקסט.

## אופרטורים
### הסבר פשוט
- **אופרטור**: סימן מיוחד שמבצע פעולה על ערכים (חיבור, השוואה, בדיקה לוגית).
- **חשיבות**: מאפשרים לקוד "לקבל החלטות" ולחשב ערכים.

### אופרטורים חשבוניים
| סימן | פעולה   | דוגמה    | תוצאה |
|------|---------|----------|-------|
| +    | חיבור   | 5 + 3    | 8     |
| -    | חיסור   | 5 - 2    | 3     |
| *    | כפל     | 5 * 3    | 15    |
| /    | חילוק   | 10 / 2   | 5     |
| %    | שארית חלוקה | 10 % 3 | 1     |
| **   | חזקה    | 2 ** 3   | 8     |

### אופרטורי השוואה
| סימן | משמעות                     | דוגמה          | תוצאה  |
|------|---------------------------|----------------|--------|
| ===  | שווה בערך וגם בטיפוס     | 5 === 5        | true   |
| !==  | לא שווה (ערך או טיפוס)   | 5 !== "5"      | true   |
| ==   | שווה בערך בלבד           | 5 == "5"       | true   |
| >    | גדול מ                    | 5 > 3          | true   |
| <    | קטן מ                     | 5 < 3          | false  |
| >=   | גדול או שווה             | 5 >= 5         | true   |
| <=   | קטן או שווה              | 5 <= 5         | true   |

### דגשים
- תמיד להעדיף `===` על פני `==`.
- `===` בודק גם ערך וגם טיפוס.

### טעויות נפוצות
- שימוש ב`==` במקום `===`.
- בלבול בין `=` (השמה) ל-`===` (השוואה).
- שכחה ש-`&&` דורש ששני הצדדים יהיו אמת.

## תנאים
### הסבר פשוט
- **תנאי**: מאפשר לקוד לקבל החלטות.
- **חשיבות**: מאפשר לתוכנית להתנהג אחרת בהתאם לנתונים.

### תחביר
- **if/else if/else**:
  ```javascript
  if (תנאי) {
      // קוד אם התנאי נכון
  } else {
      // קוד אם התנאי לא נכון
  }
  ```

- **switch**:
  ```javascript
  switch (expression) {
      case value1:
          // קוד
          break;
      default:
          // קוד אם לא נמצאה התאמה
  }
  ```

### דוגמה ב-JavaScript
```javascript
let age = 20;
if (age >= 18) {
    console.log("אתה מבוגר");
} else {
    console.log("אתה קטין");
}
```

### דגשים
- חייבים `break` בסוף כל `case` ב-switch.
- `if` בודק תנאי, `else if` תנאי נוסף, `else` ברירת מחדל.

### טעויות נפוצות
- לשכוח `break`.
- להשתמש ב`=` במקום `===/==`.
- לשכוח סוגריים מסולסלים `{}` כשיש כמה שורות.

## לולאות
### הסבר פשוט
- **לולאה**: גורמת לקוד לחזור על עצמו מספר פעמים.
- **חשיבות**: חוסכת קוד וטעויות.

### תחביר
- **for**:
  ```javascript
  for (let i = 0; i < 5; i++) {
      // קוד שיחזור על עצמו
  }
  ```

- **while**:
  ```javascript
  while (תנאי) {
      // קוד שיחזור על עצמו
  }
  ```

### דוגמה ב-JavaScript
```javascript
for (let i = 1; i <= 5; i++) {
    console.log(i);
}
```

### דגשים
- `for` — כשידוע מראש כמה חזרות.
- `while` — כשלא בטוחים כמה חזרות.
- לולאה חייבת עדכון כדי לא להפוך ללולאה אינסופית.

### טעויות נפוצות
- לשכוח לעדכן מונה בלולאה.
- טעות ב`i < 5` במקום `i <= 5`.
- לשכוח סוגריים מסולסלים `{}`.

## פונקציות
### הסבר פשוט
- **פונקציה**: חבילת קוד עם שם, שניתן "לקרוא לה" בכל פעם שרוצים.
- **חשיבות**: עוזרות לא לחזור על קוד.

### תחביר
```javascript
function functionName(parameters) {
    // קוד
    return value; // אופציונלי
}
```

### דוגמה ב-JavaScript
```javascript
function greet(name) {
    return "שלום, " + name + "!";
}
console.log(greet("נועה")); // שלום, נועה!
console.log(greet("דניאל")); // שלום, דניאל!
```

### צורות כתיבה
1. **Function Declaration**:
   ```javascript
   function f() {}
   ```

2. **Function Expression**:
   ```javascript
   const f = function() {};
   ```

3. **Arrow Function**:
   ```javascript
   const f = () => {};
   ```

### דגשים
- `Function Declaration` עובד לפני ההגדרה.
- `Function Expression` ו-`Arrow Function` לא עובדים לפני ההגדרה.

## מערכים
- **הגדרה**: מערך הוא רשימה מסודרת של ערכים, שמורים תחת משתנה אחד.
- **למה צריך מערכים?**: כמעט כל תוכנית אמיתית עובדת עם רשימות (מוצרים, משתמשים, ציונים).
  
### יצירה וגישה
- דוגמה: `console.log(fruits.length); // 3`

### מתודות לשינוי המערך
- **push(x)**: מוסיפה בסוף.
- **pop()**: מוציאה מהסוף.
- **shift()**: מוציאה מההתחלה.
- **unshift(x)**: מוסיפה בהתחלה.

### מתודות לעיבוד נתונים (לא משנות את המקור)
- **forEach(fn)**: מריצה פונקציה על כל איבר, לא מחזירה כלום.
- **map(fn)**: יוצרת מערך חדש עם תוצאה לכל איבר.
- **filter(fn)**: יוצרת מערך חדש רק עם איברים שעברו תנאי.
- **find(fn)**: מחזירה איבר בודד ראשון שמתאים לתנאי.
- **includes(x)**: בודקת אם ערך קיים במערך.
- **reduce(fn, start)**: מצמצמת את כל המערך לערך אחד.

### דוגמאות
```javascript
const numbers = [1, 2, 3, 4, 5];
const doubled = numbers.map(n => n * 2); // [2, 4, 6, 8, 10]
const evens = numbers.filter(n => n % 2 === 0); // [2, 4]
const total = numbers.reduce((sum, n) => sum + n, 0); // 15
```

### מה חשוב לזכור
- אינדקס במערך מתחיל מ-0.
- `push/pop/shift/unshift` משנים את המערך המקורי.
- `map`, `filter`, `reduce` הן המתודות החשובות ביותר.
- טעויות נפוצות: לשכוח שאינדקס מתחיל מ-0, לבלבל בין `map` ל`forEach`, לצפות ש-`filter/map` ישנו את המערך המקורי.

## אובייקטים
- **הגדרה**: אובייקט הוא דרך לאחסן מידע מובנה על "דבר" אחד, בעזרת זוגות מפתח-ערך.
- **למה צריך אובייקטים?**: אובייקט כמו "משתמש" משקף בצורה טבעית תכונות שונות.

### יצירה וגישה
```javascript
const person = { firstName: "נועה", lastName: "כהן", age: 30 };
console.log(person.firstName); // Dot notation
console.log(person["firstName"]); // Bracket notation
```

### עדכון, הוספה ומתודות
- `this` מצביע על האובייקט עצמו שבתוכו נמצאת המתודה.
- **הוספת תכונה חדשה**: ניתן להוסיף תכונות לאובייקט קיים.
- **מחיקת תכונה**: ניתן למחוק תכונות מאובייקט.

### דפוס חשוב: מערך של אובייקטים
```javascript
const users = [{ name: "דניאל", age: 25 }, { name: "נועה", age: 30 }];
const names = users.map(user => user.name);
```
- **למה זה חשוב?**: כך בדרך כלל נראים נתונים אמיתיים — רשימת משתמשים, מוצרים בחנות וכו'.

### מה חשוב לזכור
- גישה עם `const` על אובייקט לא מונע לשנות תכונות בתוכו.
- `this` מצביע על האובייקט.
- דפוס נפוץ: מערך של אובייקטים.
- טעויות נפוצות: לגשת עם `person[firstName]` (שגוי), לשכוח `this` בתוך מתודה, לבלבל בין `const` לשינוי אובייקט.

- תנאים (if/switch) ולולאות (for/while) שולטים על זרימת הקוד.
- פונקציות מאפשרות שימוש חוזר בקוד.
- מערכים: `map/filter/reduce` כמלכות התחום.
- אובייקטים.
